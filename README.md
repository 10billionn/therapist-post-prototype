# Therapist Post Prototype

店舗HP内のセラピスト発信機能プロトタイプです。

## 構成

- `app/`: App Router のページ
- `components/`: UI コンポーネント
- `data/`: ダミーデータ
- `lib/`: 補助関数とテンプレ定義
- `types/`: TypeScript 型定義

## 開発

このフォルダで実行します。

```bash
npm install
npm run dev
```

## 補足

ルート直下の `app.js` `index.html` `script.js` などは既存のシフトダッシュボード用です。
このプロトタイプとは別物として分離しています。
